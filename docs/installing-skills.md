# Installing skills

The portable unit is a skill directory containing `SKILL.md` and
`metadata.json`.

- **Claude Code:** copy the directory into the project's supported skills or
  plugin location, then restart or reload skills.
- **Codex:** install the directory through a skill/plugin location supported by
  your Codex version.
- **Cursor, Gemini CLI, GitHub Copilot:** place the instructions where that
  tool discovers project or reusable agent instructions, and verify behavior
  with a small task.

Tool-specific discovery paths change over time. Do not assume a path from
another tool is compatible; use the current platform documentation.
