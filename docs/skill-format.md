# Skill format

`SKILL.md` starts with YAML frontmatter containing `name` and `description`,
followed by concise instructions, workflow, constraints, and verification.
`metadata.json` records identity, category, tags, provenance, licensing,
adaptation status, and supported environments. `USE_INSTRUCTIONS.md` documents
how other agents, orchestrators, or conversations should invoke or delegate to
the skill. Keep optional examples and references inside the skill directory.
